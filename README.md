# Syncoo

Official downloads for the Syncoo desktop app.

## Download

Get the latest version from the [Releases page](https://github.com/kunlunli/syncoo-release/releases/latest).

| Platform | File |
| --- | --- |
| macOS (Apple Silicon) | `Syncoo-darwin-arm64.dmg` |

## Install (macOS)

1. Open `Syncoo-darwin-arm64.dmg`.
2. Drag **Syncoo** into the **Applications** folder.
3. Launch Syncoo from Applications.

The app is signed with an Apple Developer ID and notarized by Apple.
